# Chocolate Sales Dashboard

## Overview
An interactive sales dashboard developed using
Microsoft Power BI to analyze chocolate sales
performance and business trends.

## Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- Data Visualization
- Data Analysis

## Dataset
The project uses chocolate sales data stored
in Excel format.

## Dashboard
The Power BI dashboard provides visual insights
into sales performance and trends.

## Project Files
- Dashboard: Power BI (.pbix) file
- Dataset: Excel (.xlsx) file
- Screenshots: Dashboard previews

## How to View
Download the PBIX file and open it using
Microsoft Power BI Desktop.
